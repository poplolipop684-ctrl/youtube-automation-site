Privacy Policy — My YouTube Automation

Last updated: October 2026

1. What this app does

My YouTube Automation is a personal tool used only by its owner. It uploads videos to the owner's own YouTube channel through the YouTube Data API v3.

2. Data we access

When the owner connects their Google account, the app can access:

  • The owner's YouTube channel (to upload videos to it)
  • Video metadata the owner provides (title, description, thumbnail)
  • The OAuth access and refresh tokens Google issues for this purpose

3. How data is used

Data is used solely to generate and upload videos to the owner's own channel. Nothing is sold, rented, or shared with any third party.

4. Data storage and retention

OAuth tokens are stored on the owner's own server and used only to perform the automated uploads the owner authorized. Data is kept only as long as the owner keeps the automation running.

5. Revoking access

The owner can revoke the app's access at any time from their Google Account security settings (myaccount.google.com > Security > Third-party access), which immediately stops all access.
